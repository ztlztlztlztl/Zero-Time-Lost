## 技术方案

沿用 QTableWidget、现有 delegate 和月份逻辑，抽出无控件依赖的 WeekLayout 计算。它根据字体、节点数及时间行计算高度与文字位置。无新增外部依赖或数据库结构调整。

### 周布局

1. 完整周数据生成节点，以分钟、稳定实例身份和端点排序。
2. 每行高度取七列所需容量最大值，不设 144 像素上限；空白连续两小时及以上仍压缩。
3. 每列文字先按分钟得到理想位置，正向推开重叠，再从底部反向收紧。容量计算保证全部文字留在本行且不重叠。
4. 每个节点保存相对行顶的文字位置；筛选在布局完成后隐藏节点，保留槽位。
5. delegate 和事件处理共享节点矩形；端点、背景与时间线共享分钟映射，连接线表达文字与真实时间位置的关系。月视图保留原有折叠。

### 日程选择

统一维护选中身份和悬停身份，选中优先。应用事件过滤器只处理 Calendar 范围内的点击，排除卡片自身及独立对话框；其他点击清除选择。所有日期分组从统一状态更新高亮，避免旧悬停残留。卡片移除虚线焦点框，以原边框表达键盘焦点。

### 全天标签

编辑器隐藏备注整行，标签保存值不包含备注内容，详情不创建备注控件；写入时规范化标签备注为空，已有存储不做批量迁移。

## 实现与验证

依次实现纯布局、周视图接入、日程选择和标签表单；补充密集／同刻／边界布局、筛选稳定性和点击交互测试。通过回归和截图验收后更新使用说明，重新打包并覆盖正式程序，校验 data 哈希。
