## 需求概述

全天标签只需要日期和内容。日程的点击选择应易于清除，周视图在保留空白压缩的同时展开繁忙时段，直接呈现所有事务节点。

## 功能需求

- P0：全天标签的新增、编辑、详情去掉备注；DDL 和区间事务保留备注。
- P0：日程点击卡片锁定唯一高亮；点另一张卡片切换；点 Calendar 内空白、日期栏或其他控件清除。
- P0：有选中项时悬停其他卡片不改变高亮，不显示卡片虚线框；没有选中项时保留区间悬停预览。
- P0：周视图同一时段的七天使用相同行高，以完整数据中所需高度最大的一天为准，允许垂直滚动，不折叠事务节点。
- P0：每个 DDL 一行，区间开始、结束各一行；每一天单列排列，节点不重叠。长标题省略，悬停查看全文。
- P0：空白压缩和繁忙扩张都基于整周完整数据，筛选不改变行高和剩余节点的位置。

## 非功能要求与边界

- 保留现有 Qt、周／月导航和月视图溢出规则；不更改循环、提醒及数据目录规则。
- 绘制和点击命中使用同一份矩形；真实时间位置、区间背景与当前时间线使用同一映射。
- 同分钟大量节点、小时边界、窄窗口及不同字体缩放下均应可读、可点。

## 验收标准

1. 打开或编辑全天标签时不显示备注；切回 DDL／区间时备注可用。
2. 选中区间后移动到其他卡片，高亮保持；点击日期／空白／Calendar 控件，高亮清除；未选中时悬停预览可用。
3. 同一分钟几十个节点在周视图全部显示，矩形互不重叠；双击可逐一打开正确详情。
4. 09:59 与 10:00、00:00 与 23:59 的节点均在所属时间行内；筛选前后行高与可见节点位置一致。
5. 构建、相关回归和部署自检通过，覆盖部署包时保留现有 data。
