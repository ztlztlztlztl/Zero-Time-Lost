## 技术方案

沿用 QTableWidget、现有 delegate 和月份逻辑，WeekLayout 负责字体相关的行高、文字槽位及时间顺序插入线计算。无新增外部依赖或数据库结构调整。

### 周布局

1. 完整周数据生成节点，按分钟、稳定实例身份和端点排序。
2. 每行高度取七列所需容量最大值；共同空白连续两小时及以上仍压缩。
3. 文字从顶部留白后依次排列，行距固定，不按分钟比例定位。完整节点先分配槽位，筛选只隐藏节点，不重新排布。
4. delegate 不再绘制时间点和连接线，卡片文字保留 HH:mm；绘制和点击共用矩形。
5. 区间背景以开始、结束文字的中心位置为边界，途经其他时间行时填满相应部分；“现在”线按完整节点的时间顺序插入。避免继续使用比例位置与顺序文字混排。
6. 月视图保留原有折叠和导航。

### 日程选择

统一维护选中身份与悬停身份。只有选中卡片禁用悬停，未选中卡片照常显示悬停效果。日期分组同时绘制选中区间和另一个被悬停的区间；移开只移除后者，避免覆盖选择。Calendar 范围内的其他点击清除选择，独立对话框除外。卡片没有虚线框，键盘焦点用原边框表示。

### 全天标签

编辑器隐藏备注整行，标签保存值的备注为空，详情不创建备注控件；已有存储不做批量迁移。

## 验证与部署

验证选择与独立悬停、鼠标移开、空白清除、同刻密集节点、不同分钟的紧凑排列、区间背景边界、筛选槽位稳定及点击身份。通过构建、全量回归、缩放与截图检查后，覆盖正式包并核对 data 哈希。
