# 云端扩展设计

## 修订记录
| 版本 | 日期 | 摘要 |
|---|---|---|
| v1 | 2026-11-05 14:30 | 初版 |

FastAPI + SQLite WAL + Docker Compose；Nginx 终止 HTTPS。IP 证书通过本地 CA 文件校验，不跳过 TLS 验证。令牌仅用于单用户访问认证。SQLite 每次修改同时提交实体、不可变修订日志、幂等请求回执；删除保留墓碑。

Qt 同步层在 data/cloud 下持久化服务端基线、待发送请求、游标、冲突及远端应用日志。业务记录沿用原始 JSON；不在服务器重新解释循环规则。首次同步合并不同 ID 的记录，同 ID 不同内容必须人工选择。服务器数据集身份变化或游标倒退时停止自动同步并提示核查。

本地变更保存后比对基线生成队列；启动重新扫描补齐中断窗口。请求发送后内容不可变，响应丢失后重发同一操作 ID。远端修改先写入应用日志，再写业务仓库，最后提交基线及游标，启动可重放。存在本地分歧时保留双方记录，用户可选择本机或云端版本。

共享设置采用明确白名单；文件书签及秘密不进入同步。邮件账户凭据只通过 HTTPS 发送到个人服务器以执行轮询。服务器摘要事务提交后再标记 IMAP 已读，失败保留待确认队列。后台任务和前台请求串行操作同一邮箱，SQLite 连接按操作创建。天气失败保留旧缓存并附带更新时间及错误。

部署目录集中管理服务、数据库、证书与备份；容器自动重启、日志轮转，SQLite 在线备份后进行完整性检查。客户端程序替换保留原 data 目录。
